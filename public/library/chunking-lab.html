Project scope

What "done" looks like for Team AI.

  1. 01 Working implementation of each of the six chunking strategies.
  2. 02 A common evaluation dataset and test-query set shared across all strategies.
  3. 03 A performance comparison run across every strategy on that dataset.
  4. 04 Metrics captured per strategy: retrieval accuracy, context preservation, response quality, latency, token usage.
  5. 05 A decision framework mapping problem type → recommended strategy, with quality/speed/cost trade-offs made explicit.
